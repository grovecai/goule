# 「斩心魔」Android 首版交互设计

首版设计。已确认的页面布局、文案和戒律保护以本文为准。交互原型用来体验流程，原生 Android 能力原型用于验证前台识别和禁用遮罩。产品行为和技术边界见 [Android 首版设计](android-design.md)，实际实现和验证进度见 [实施计划](implementation-plan.md)。

## 设计意图

「斩心魔」帮助用户中断正在发生的一次无意识刷屏。用户在清醒时选好 App 和时间，用满后由 App 执行这条预先设定的界线。主要流程只有选 App、定时长和保存戒律。禁用页给出明确的停止信号、恢复时间和退出动作。

视觉上，欢迎页用全屏救援画面表达脱离刷屏循环。戒律页用剑光穿过紫色风暴的插画提醒用户守住界线，设置页延续深紫、暖白和金色。禁用页用同一修仙画风的戒律长老和强烈的漫画对白打断当下动作。文案以「守道心」串起欢迎、日常提醒和喝止，权限、计时、恢复与退出动作继续用直白术语。

### 行为研究说明

行为研究支持把一次停顿放在习惯动作发生的时刻。Wood 等人观察到，情境变化会打断一些习惯行为。Wellspent 的随机试验在用户自定的时限到达时显示可选择退出或继续的全屏提醒，干预组在其最想少用的 App 上使用时间减少。研究为设计思路提供依据。强制禁用、默认时长和漫画喝止各自的效果仍需由「斩心魔」验证。[习惯与情境变化研究](https://pubmed.ncbi.nlm.nih.gov/15982113/) · [Wellspent 随机对照试验](https://pmc.ncbi.nlm.nih.gov/articles/PMC13062480/)

后续可评审「停一下，为什么有用？」作为可选的研究说明入口。欢迎页的两行文案已经确定，研究说明页仍为提案。

## 用户界面术语

| 概念 | 统一写法 |
| --- | --- |
| 产品名称 | 独立名称显示为 `斩心魔`，出现在按钮或句子中时加直角引号，例如 `打开「斩心魔」` |
| 为 App 设置的规则 | 戒律 |
| 选择器里容易让人刷到停不下来的 App | 心魔 |
| 戒律字段 | 可刷时长、休息时长；两者相加为滚动窗口长度 |
| 紧凑时长摘要 | 刷 20 分钟，歇 30 分钟；详情解释任意连续 50 分钟最多刷 20 分钟 |
| 单条戒律状态 | 可刷、禁用至 14:50、未生效、找不到此 App |
| 设置页无障碍服务状态 | 未开启、正在连接、已连接 |
| 戒律页执行提示 | 戒律未生效、戒律已暂停 |
| 操作 | 添加心魔、修改戒律、保存戒律、移除戒律、返回桌面 |
| 目标 App 用满时长 | 禁用页、预计 14:50 恢复使用 |

「暂停」用于计时暂时停下和戒律暂停。目标 App 的限时状态用「禁用」，Android 权限入口用「无障碍服务」。

## 页面结构

| 入口 | 页面与主要操作 |
| --- | --- |
| 首次启动 | 欢迎页 → 权限说明 → 系统无障碍设置 → 添加第一个 App |
| 戒律 | 戒律首页 → 添加心魔 → 设置时长，或点开已有戒律进入详情、修改和移除 |
| 设置 | 服务状态、打开系统无障碍设置、开启帮助和戒律保护 |
| 目标 App 用满额度 | 禁用页 → 返回桌面，或等待禁用到期自动恢复 |

应用内的授权、选 App、表单、详情、确认与说明页延续无插画的深紫渐变，使用暖白文字、金色主操作、细线及深紫输入框。Android 系统授权页使用系统外观。

首页使用「戒律」「设置」两个底部入口，详情和表单用系统返回回到上一页。禁用页跟随目标 App 显示。

## 首次使用与授权

1. 欢迎页以救援插画铺满窗口。标题「斩断无尽的下滑，守住道心」放在左上暗部，一名修行者被心魔化成的紫黑倒影和魔气缠住，正咬牙抓住金光里伸来的援手。人物的脸、心魔和握住的手集中在画面中段，左下角完整露出坠落的手机，呼应刷屏主题。短屏时将主体插画上移，让手机避开下方文案。两行文案、时长示例和金色「立下第一条戒律」集中在底部，形成稳定的操作区。欢迎页省去独立的产品名标题。
2. 两行文案为「你清醒时立下戒律」和「心魔上头时，替你斩断刷屏循环」。下方用黑底白色场记板与青红错位边缘代表短视频 App，省去示例 App 名。「刷 20 分钟，禁 30 分钟」用青底白字的「刷」和红底白字的「禁」两枚方印显示。用户先理解目的，再看具体例子。
3. 点击「立下第一条戒律」进入独立权限说明页。权限说明解释「斩心魔」使用无障碍服务识别前台 App 和切换时间，为设置了戒律的 App 计时并显示禁用页。数据用途、本机保存和关闭服务的说明合并进同一段。
4. 点击「同意并前往设置」后，由用户在 Android 系统设置开启「斩心魔」。回到「斩心魔」后，系统开关已开启且服务已连接时，设置页显示「已连接」。首次授权后进入后台运行设置，说明第 2 步并提供系统入口。用户继续后打开 App 选择器，已有戒律时返回戒律首页。取消选择回到空戒律首页。
5. 点「稍后」、从系统设置返回时尚未开启，或授权被拒绝，首次点「稍后」也进入后台运行指引，提供开启无障碍服务入口，继续后可配置戒律。戒律首页显示「戒律未生效」及「去开启」入口。用户仍可添加和修改戒律，保存后显示「未生效」。服务连接后才开始计时。

「查看开启帮助」按顺序说明如何在系统的「已下载的应用」中找到「斩心魔」、开启服务，以及回到应用后如何确认生效。Android 13 及以上另列出遇到「受限制的设置」提示时的应用信息入口。关闭帮助回到原页面。 [Android 受限制设置说明](https://support.google.com/android/answer/12623953?hl=zh-Hans)

## 戒律首页与状态

空列表显示「戒律」和「立下第一条戒律」，提示「挑一个让你刷到停不下来的 App，给它立条戒」。已有戒律时使用竖屏剑光插画。人物和剑光集中在上半屏，下半屏渐入低纹理的深紫云层，让首屏戒律有稳定的文字对比度。戒律上滑时逐渐加深阅读区域的背景。

两行标语「道心自己守」「心魔上头，一剑斩断」直接浮在画上，行末省去标点。「道心」用浅青，「斩断」用暖金。右侧是「＋」按钮，无障碍名称为「添加心魔」。戒律行和底部导航用细线分隔，「＋」、状态标签和「刷／歇」印章保留底色。底部导航用金色标记当前页。

每行显示 App 图标、名称和一条状态，时长沿用欢迎页的「刷／歇」方印和分钟数，详情使用同一套摘要。列表在配置时长下补充金色「还可刷 19 分 42 秒」，整分钟显示「还可刷 20 分钟」，不足一分钟显示秒数，毫秒向上取整至秒。剩余量使用每个 App 独立累计的额度，查看列表不会扣减；回到列表及页面停留期间自动刷新。禁用中显示「还可刷 0 秒」，旧用量过期时逐步恢复额度，不在恢复起点一次补满。禁用中的 App 按预计恢复时间排序并置顶，其余按名称排序。「可刷」表示当前可用，服务暂停或目标缺失时保留原状态提示，额度仅反映已记录用量。使用历史留待后续。

| 状态 | 首页和详情如何显示 |
| --- | --- |
| 可刷 | 「可刷」和戒律参数，例如「刷 20 分钟，禁 30 分钟」 |
| 禁用中 | 「禁用至 14:50」，跨日时带日期。时间到达后显示「可刷」，旧用量开始逐步释放，未过期用量继续占额度。 |
| 服务关闭或断开 | 此前已启用时显示「戒律已暂停」，提供恢复入口。受影响的戒律标记为「未生效」。仍有效的禁用截止时间可在详情显示为「服务连接后，禁用至 14:50」。 |
| App 已卸载或无法找到 | 行内显示「找不到此 App」。详情保留配置，提供「重新选择心魔」和「移除戒律」。 |

初次尚未启用时，戒律页提示「戒律未生效」，说明开启无障碍服务后才会生效。系统开关已打开但服务未连接时，设置页显示「正在连接」，戒律页提供「检查服务」入口。限制暂停期间保留戒律和已记录用量，暂停时段不累计。恢复连接时按当前时间检查禁用截止，仍有效的禁用继续执行，已到恢复时刻的戒律按当前滚动窗口内有效用量计算剩余。

## 添加、修改与移除

### 添加心魔

1. 点「添加心魔」，进入本机可启动 App 的单选列表。列表按名称排序，显示图标和名称。「搜索心魔」按 App 名称匹配。同名 App 补充包名以便区分。桌面、设置、电话、紧急入口和「斩心魔」自身从列表排除。
2. 已添加的 App 标记「已添加」，点开现有戒律详情。选中新 App 进入表单。搜索无结果时显示「未找到匹配的心魔」，提供清除搜索入口。
3. 表单显示目标 App，使用两项以分钟为单位的整数输入。可刷时长默认 20 分钟，范围 1–180 分钟。休息时长默认 30 分钟，范围 15–180 分钟。修改后更新戒律预览，例如「任意连续 50 分钟内，最多刷 20 分钟。旧用量过期后逐步恢复额度。」
4. 主按钮为「保存戒律」。输入有误时在对应字段下显示有效范围。保存失败保留输入并允许重试。保存成功回到戒律首页，按实际服务状态显示「可刷」或「未生效」。返回时若已有未保存的修改，提供「继续编辑」「放弃修改」。

### 修改与移除

- 详情显示 App、当前状态、配置参数、当前实际执行的窗口说明及恢复时间。「当前戒律」卡片增加金色「还可刷」读数，与列表复用额度计算；查看不扣时，停留期间刷新。旧用量逐毫秒过期，不一次补满额度。修改复用时长表单，保存保留有效使用区间和首次计时固定的可刷额度/窗口长度；当前有效用量全部过期后采用最新配置，尚未计时则立即采用。持续使用替换额度会延后新参数生效，详情明确显示当前窗口和待生效提示。编辑表单保存前说明该行为。
- 同一戒律每 5 分钟可成功修改一次，从上次保存实际修改起算。等待期间禁用修改入口并显示剩余时间。只打开表单或保存相同的参数时，沿用原有修改时间。
- 新建戒律满 1 小时后方可移除。每次开始禁用时重新等待 1 小时，禁用提前结束时仍按该次开始时间算。等待期间显示剩余时间。可移除时，点「移除戒律」后确认，按钮为「取消」「移除」。禁用中的戒律额外说明「移除后，此 App 会恢复使用」。完成后返回列表。
- 找不到原 App 时，可重新选择并带入两项时长。确认替换后，新 App 开始自己的使用轮次。若所选 App 已有戒律，打开其详情，保留原戒律供用户处理。重新选择沿用该条戒律的保护时间，避免通过换 App 绕过等待。
- 5 分钟间隔和 1 小时等待用于减少刷上头时临时改掉戒律的冲动。两项等待按每条戒律分别计算，禁用结束时间和可移除时间分别显示。
- 每段用量在该段发生后经过「可刷时长＋休息时长」逐步过期。午夜、退出重进、修改及重启不会额外发放额度；升级前已生效的旧禁用截止作为迁移下限保留。

## 禁用页与恢复

目标 App 用满额度时显示独立禁用页。上方是怒视前方、伸手直指屏幕的戒律长老。深紫风暴与金红雷光延续戒律页的画风。暖纸色对白框叠在插画下缘，分三层显示「够了！」「别刷〔App 名称〕了！」「再刷下去，你还飞不飞升了？」。对白中的 App 名称随当前目标替换，并用深紫色突出。页首直接进入插画。「解禁时刻」以及「斩退心魔」和低强调的「回洞府」按钮放在对白下方，让用户先看到喝止，再找到离开的办法。跨日时带日期，解禁时刻使用系统时间格式。短屏压缩插画高度，让两个退出按钮尽量同时出现在首屏。遮罩可见时目标 App 的内容无法接收触摸，系统导航保留。

点「斩退心魔」打开系统最近任务，提示用户上滑目标 App 卡片。卡片的预览由 Android 生成，可能显示目标 App 的原画面。点击仍在禁用的卡片会重新显示遮罩。「回洞府」由用户点按后触发。操作失败时保留遮罩，提示「请使用系统导航返回桌面」。在同一次禁用内重新进入目标 App，显示相同的截止时间。用户切到其他 App、锁屏或服务断开时撤下遮罩，禁用按现实时间继续。到期时自动撤下遮罩，用户可继续操作目标 App，按旧用量释放的速度逐步恢复额度；连续操作时新用量替换过期用量。

「显示测试操作」位于交互原型的手机界面外，默认关闭。开启后可「模拟到期」或快进 5 分钟、1 小时，用于验收戒律保护。Android 正式构建仅按实际截止时间恢复，测试入口仅供测试构建使用。

## 设置与可访问性

- 设置延续无插画的深紫渐变。显示无障碍服务状态、开启入口、开启帮助和两条戒律保护说明。「修改：每条戒律两次修改至少间隔 5 分钟。」「移除：创建后要等 1 小时。每次开始禁用时，重新等 1 小时。」数据用途和本机保存说明集中放在授权页。
- 竖屏按实际窗口宽高和系统安全区适配。以 OPPO 的约 360 × 791 dp 为基准，另对照 360 × 640、390 × 844 和 412 × 915。短屏压缩插画留白，内容可滚动。剑光背景按宽度优先保留双脸和剑光，较高窗口向下接深紫底。
- 状态使用文字表达，颜色只作辅助。戒律行和表单支持系统大字号与 TalkBack，禁用页按对白、恢复时间、操作的顺序朗读。按钮使用明确的动作名称。
- 24 小时戒律保护、提醒和使用历史留待后续。系统始终保留关闭无障碍服务和卸载「斩心魔」的入口。

## 桌面图标

桌面图标采用「一剑断魔」黑曜石版。白色斜向剑光斩开带紫色独眼的黑曜石魔像，裂口透出金光。48 px 预览仍可辨认剑光和魔像轮廓。显示轮廓由启动器处理。

## 验收场景

| 场景 | 通过条件 |
| --- | --- |
| 暂缓授权与恢复 | 暂缓后可保存戒律，戒律显示「未生效」。系统开关开启且服务连接后，戒律才开始执行。 |
| 滚动窗口与边界 | 刷 10/歇 120，连续使用在第 130 分钟开始恢复、第 135 分钟仅恢复 5 分钟；分段 0–5、60–65 分钟用量各自在 130–135、190–195 分钟释放，跨周期不能额外获得完整额度。 |
| 多 App 独立 | A 用满时只有 A 禁用，B 可继续使用。A 和 B 同时禁用时各自到期。 |
| 可刷期间修改 | 原定刷 20 分钟、已刷 8 分钟，改禁用时长或将可刷时长增减后仍只剩 12 分钟；按原额度和原窗口继续执行，有效用量全部过期后采用最新参数；其他 App 用量不变。 |
| 禁用期间修改与移除 | 修改保留当前有效记录及窗口快照，新时长在有效用量全部过期后生效。同一戒律的第二次修改至少等 5 分钟。创建和最近一次禁用开始均满 1 小时才可确认移除，确认后解除该戒律的限制。 |
| 断开与重连 | 断开后撤下遮罩，列表显示暂停。重连后仅恢复仍有效的禁用。 |
| 锁屏与唤醒 | 锁屏期间使用额度不增加，禁用时间继续流逝。解锁直接回到目标，以及解锁后从桌面重新进入，分别验证。 |
| 遮罩与系统入口 | 遮罩可见时触摸不传到目标内容，到期后恢复交互。系统导航、设置、来电和紧急入口可用。 |

OPPO 已验证禁用主流程及两条息屏恢复路径。来电、紧急入口及更多设备的结果见 [真机记录](verification.md#真机记录)。

## 后台运行设置

设置页新增「后台运行设置」，显示实时无障碍连接状态和系统电池优化豁免状态，提供电池优化与应用信息入口。OPPO 显示允许后台活动、自启动及最近任务锁定指引，其他厂商使用通用说明。厂商开关由用户在系统内确认，不以已读标记推断完成。返回页面重新读取状态。

首次欢迎页明确提示需开启无障碍服务并允许后台运行。权限说明页标明第 1 步及下一步的后台设置用途。设置页将后台运行独立成节，强调系统清理会中断计时和禁用，并突出后台运行设置按钮。后台指引可继续添加心魔或返回已有戒律，不以继续按钮推断厂商设置完成。
