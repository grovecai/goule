# 禁用页主题

入口：设置 → 禁用页主题。所有戒律共用一套主题集合，显示方式只有「固定主题」「随机主题」。内置主题与自定义主题都可在固定下拉框选择，也可在随机池勾选；页面只展示当前一张主题卡片。

每个主题完整包含名称、图片、喝止台词、提醒台词和两个操作按钮名称。主题决定文字与画面，按钮动作固定为打开最近任务、返回桌面；解禁时间、目标 App 名和实际禁用规则保持独立。预览复用真实禁用页，示例 App 和时间明确标为预览；预览的两个按钮都返回主题设置。

## 新增与编辑

点击「新增主题」，填写主题名（最多20字）、喝止（16字）、提醒（80字）和两个按钮名称（各6字），选择图片后点「保存主题」。可以新增多个主题。新主题自动加入随机池，并成为固定选择；当前处于随机模式时保持随机模式。保存后与内置项一起出现在相同的下拉与多选弹窗中。

选中自定义主题后可点「编辑这个主题」，更新图片、台词、按钮名称及主题名；稳定 ID 保持不变，原有随机勾选也保持。选择图片只处理草稿，不立即覆盖已保存主题。返回时可继续编辑或放弃；取消选图、处理失败和放弃草稿均不改变旧主题。页面重建保留表单字段和图片草稿。

## 选择与删除

- 固定模式从同一个下拉框选择任意可用主题，立即保存。
- 随机模式在「选择随机主题」弹窗勾选并保存，可以混选内置和自定义主题，也可只选个人主题；取消保留原值，至少保留一个。每次新建禁用页时等概率抽取，同一遮罩停留、计时刷新和旋转时保持稳定，不承诺相邻两次不重复。
- 随机模式的「管理主题」下拉框用于查看、编辑或删除，不更改显示模式或随机勾选。
- 原戒律长老不可删除；其他主题可确认删除。删除当前固定项或随机池唯一项时回到原长老，模式保持。自定义主题删除元数据和私有图片文件；内置主题删除记录跨保留数据升级保留，APK 中的原资源无法由运行中的 App 逐项移除，APK 体积不变。

内置主题包含下表六项：原五项保持用户指定顺序，末尾新增「亲妈催婚」。魔法劝退、菜地除草、月老催婚、出门晒太阳、戒刷心魔，以及此前的奶瓶召唤，已从目录、图片资源和生成清单移除。「亲妈催婚」使用独立 ID `mother`，不复用退休的 `marriage`。旧固定项或预览失效时回到原长老；随机池只过滤退休项，保留有效项和个人主题，空池回到长老。用户自定义主题、图片与已删除记录均保留；新增内置项不覆盖已有固定选择或主动加入已保存的随机池。

## 数据与兼容

主题内容保存在独立私有外观首选项，个人图片在 `noBackupFilesDir/block-themes/`，不上传、不备份、不增加权限。系统文件选择器的临时授权只用于立即复制；最多20 MiB、1亿像素的图片在后台处理，最长边限至1440，保存静态 WebP。草稿在本机缓存，主题保存时先写新图片、再提交完整元数据，成功后才清理旧图；失败保留已保存版本。

旧版单张图片迁移为「我的主题」，图片、默认台词和原按钮名都保留；旧 `CUSTOM` 模式转为固定选择该主题，不再作为显示方式。已有随机勾选、明确排除和内置删除记录保留；尚未支持个人图片随机的更早版本只补入一次。图片无法读取、主题已删除或退休时安全回退原长老，不放开禁用遮罩。迁移和编辑均不写规则存储。

自动化与设备实际结果见 [验证手册](verification.md)。选择/内容/编解码检查和隔离包的表单、图片、迁移、按钮及布局回归已接入 `./scripts/check`（设备部分由 `GOULE_UI_DEVICE` 启用）。
