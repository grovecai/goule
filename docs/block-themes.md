# 禁用页主题

入口：设置 → 禁用页主题。设置对所有戒律生效，只改变禁用页展示。原有用户默认保持「戒律长老」。

- **固定主题**：选定一个内置主题，之后一直显示。
- **随机主题**：从勾选的内置主题中等概率抽取，可以排除婚育等不适合自己的场景，至少保留一个。每次重新进入禁用页时抽取；同一页停留、计时刷新和横竖屏重排保持所选主题，不承诺相邻两次不重复。自定义图片不加入随机池。
- **自定义图片**：通过系统文件选择器选择图片，导入成功后自动启用。可预览、替换和删除；取消或失败保留原图及模式。删除当前自定义图回到默认长老。缺图、损坏或旧主题 ID 失效时，禁用遮罩仍显示默认主题，不放开目标 App。

预览复用真实禁用页布局，顶部标明预览和返回入口，App 名与解禁时间为示例。预览里的两个退出按钮都返回主题设置，不执行系统最近任务或返回桌面。预览和选择主题不会消耗可刷额度、建立周期或修改禁用截止。所有模式保留「别刷〔App 名〕了！」、真实解禁时刻、「斩退心魔」和「回洞府」。

## 图片与存储

十张新图由内置 `image_gen` 生成，最终资源位于 `app/src/main/res/drawable-nodpi/block_*.webp`，每张 960 × 640；共约 1.7 MiB。完整生成提示词及各资源路径保存在 [提示词清单](block-theme-prompts.json)。原长老图保留。

自定义图片不上传服务器，不增加相册、存储或联网权限。系统 `ACTION_OPEN_DOCUMENT` 返回的临时读取授权只用于立即复制，不保存 URI 或申请长期读取授权。后台线程对最多 20 MiB、最多 1 亿像素的可解码图片进行校验，`ImageDecoder` 处理方向并将最长边限至 1440 像素，保存静态 WebP；动画只使用静态画面。图片完整适配插画区域，横竖屏均不裁切；其余位置保留不透明背景与原生文案和退出按钮。

模式/主题池保存在独立 `block_appearance` 私有首选项，规范化图片使用 `AtomicFile` 写入 `noBackupFilesDir/block-image.webp`。替换写入失败保留旧文件；删除清除该图。未提交的导入在进程被系统终止时可能需要重新选择图片。应用备份原本已禁用，图片目录也明确不参加备份。处理、替换或删除主题均不写入规则存储。

## 验证

自动化与设备实际结果见 [验证手册](verification.md#多主题禁用页2026-11-16)。`BlockThemesTest` 覆盖选择策略；`BlockThemeChecks` 在隔离包中检查原生布局、模式持久化、预览与导入回退；这些已接入 `./scripts/check`（设备部分由 `GOULE_UI_DEVICE` 启用）。
