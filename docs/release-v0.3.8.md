# 斩心魔 v0.3.8

优化横屏禁用页，继续作为预发布版本提供测试。

## 更新内容

- 横屏改为左右分栏：左侧显示戒律长老插画，右侧显示对白、解禁时刻和两个退出按钮。
- 「斩退心魔」「回洞府」固定在右侧底部，无需滚动即可操作。长 App 名或大字号时，仅对白区域滚动。
- 根据遮罩实际可用窗口尺寸重排，适配横竖屏和窗口大小变化，并保留原禁用截止及系统安全边距；竖屏继续使用上下漫画构图。
- 保留 v0.3.7 的独立固定周期、计时文字原位更新和无障碍中断恢复指引。

发布检查包含 `./scripts/check`（Debug/Release 各 41 项单元测试、Lint、Debug 与页面回归 APK 构建）、Release 构建、APK 元数据、原发布证书和 ZIP 对齐校验。

OPPO PLJ110（Android 16、ColorOS V16.1.0）独立包使用生产视图完成 Android 布局、渲染和触摸分发回归，覆盖 640×320、800×360、640×240 dp、1/1.3/2 倍字号、长 App 名、跨日时间、安全边距及同一视图的横竖尺寸往返；两个按钮均完整可见并能接收触摸，退出回调检查通过。既有列表/详情跨预置重置点的原位更新回归通过。布局测试不创建真实服务遮罩、不执行系统全局操作。

同功能的 afb5f23 原签名 Release（0.3.7/code 10）已覆盖安装至该 OPPO，启动、已采集的戒律数据、安装包摘要和实际服务绑定核对通过。本次 0.3.8/code 11 版本包未另装手机；真实目标遮罩的物理旋转、最近任务退出/点回、回桌面、触摸不透传、到期撤罩及锁屏/重连仍待复测，不以布局回归代替这些端到端结果。

## 已知问题与边界

- ColorOS 重启或清理可能关闭无障碍服务，需手动恢复；后台允许和任务锁定可减少中断，不能保证系统杀服务后的自动恢复。
- 真实来电挂断后，仍在禁用中的目标 App 可能未自动恢复遮罩，返回桌面再进入可恢复，尚未修复。
- 同意权限说明但未开启服务时，重启 App 可能直接进入戒律首页；缺项提示及添加门禁仍有效，首次引导恢复问题尚未修复。
- 大字号下固定高度时长印章仍可能裁切；完整自然周期及更多品牌设备尚待复测。
