# Goule 验证手册

## 本地检查

运行 `./scripts/check`。需要 Bash、Git 和 Python 3。脚本检查 Git 改动的空白错误、仓库导航文档以及 Markdown 行内相对链接指向的文件。Android 工程接入后，脚本通过仓库内的 Gradle Wrapper 运行 `check assembleDebug`。

## 能力原型真机验收

在 Pixel 或接近原生的设备以及至少一款国产 ROM 上执行。用调试短额度复现下列路径。

1. 从系统设置启用服务，确认服务连接。进入目标 App、切出、重新进入和锁屏，观察前台识别及计时暂停。
2. 用完额度，确认遮罩出现且触摸无法传到目标 App。点「返回桌面」，重新打开目标 App，确认冷冻期间仍会拦截。
3. 等待冷冻结束，确认遮罩撤下且可以开始新一轮。冷冻期间检查其他 App、系统导航、系统设置、来电与紧急入口的可用性。用系统设置关闭服务，确认遮罩撤下。
4. 记录提交 SHA、机型、Android 和 ROM 版本、安装来源、各步骤结果、观测延迟及异常复现步骤。未执行的项目标记为待验证。
