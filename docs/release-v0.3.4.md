# 斩心魔 v0.3.4

本次更新简化后台配置，并明确无障碍服务关闭后的恢复操作。继续作为预发布版本提供测试。

## 更新内容

- 后台运行改为可选指引：不再显示无法可靠检测的完成状态，移除手动确认、撤销确认和后台配置门槛。首次第 2 步可以直接继续，无障碍服务仍需开启。
- 后台页保留「耗电管理」「电池优化」两组步骤和入口，标明 OPPO 专用路径与 Android 通用机制的界面差异。
- 曾启用的无障碍服务被关闭时，显示「已关闭／戒律已暂停」，并提供「重新开启无障碍」入口；重新连接后自动清除暂停提示。
- 补充 OPPO 重启撤权及「保持开启」二次提醒说明，原有戒律和仍有效的禁用截止时间保留。

## 已知问题与使用边界

- OPPO PLJ110 / ColorOS 16.1.0 实测会在重启后因侧载来源撤销无障碍授权；完全允许后台行为也不能避免。本次改善恢复提示，**没有实现自动重新授权**，重启后请检查并手动开启服务。
- 默认「智能优化后台运行」下划掉任务可能关闭服务；本机选择「完全允许后台行为」后，划掉任务和一键清理测试通过。后台指引仍由用户按需配置。
- 真实通话挂断后，仍在禁用中的目标 App 可能未自动恢复遮罩；返回桌面再进入可恢复。此问题尚未修复。
- 同意权限说明但未开启服务时，重启 App 可能直接进入戒律首页；首页缺项提示及添加门禁仍有效。首次引导恢复问题尚未修复。

## 安装与验证

下载 `goule-v0.3.4.apk`，支持 Android 11 及以上，版本码 7。沿用原发布签名，可覆盖已有签名发布版并保留本机配置。安装后检查无障碍服务，部分系统需要重新开启。附 `goule-v0.3.4.apk.sha256` 供校验。

`./scripts/check`（仓库检查、Lint、单元测试、Debug 构建）、Release 构建、签名及 ZIP 对齐校验通过；发布证书与 v0.3.3 一致。

相关功能已在 OPPO PLJ110（Android 16、ColorOS 16.1.0）验证，完整结果包括通过、失败及未覆盖项。本次版本号更新后的 APK 不等同于重新完成全部真机用例；过夜待机、其他品牌及实际受限设置解除仍未覆盖。
