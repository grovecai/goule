# 斩心魔 v0.3.11

将「风险行为拦截白名单」改为独立设置项，并修正「手机管家」服务说明，继续作为预发布版本提供测试。

## 更新内容

- 设置页新增与无障碍、后台运行并列的「风险行为拦截白名单」条目，进入独立指引页。
- 无障碍页提供常显入口，无需展开「遇到问题」；后台页也提供直接入口，移除重复铺开的白名单步骤。独立页返回来源页面，首次配置仍保持原两步。
- 明确 OPPO/ColorOS 的「风险行为拦截」是系统自带「手机管家」中的服务。其他品牌仅说明部分厂商提供，入口和名称因品牌、系统版本而异，没有此服务可略过。
- 保留加入白名单及手动恢复无障碍的步骤，不新增完成状态或设置门禁，不更改戒律与计时行为。
