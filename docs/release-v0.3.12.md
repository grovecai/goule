# 斩心魔 v0.3.12

首次欢迎引导改为三步顺序进行，并记住未完成的步骤，继续作为预发布版本提供测试。

## 更新内容

- 首次使用按「无障碍服务 → 允许后台运行 → 风险行为拦截白名单」顺序经过，页头显示第 1/2/3 步，最后再进入添加心魔。
- 后台页的下一步进入白名单指引，首次隐藏跨步快捷入口。白名单页可以返回后台页，没有对应厂商服务时可直接继续；无障碍实际连接后，点击最后一步继续才记录引导完成。
- 未完成引导时保存当前步骤，重新打开应用会恢复到该步骤，修复仅同意无障碍说明后重开可能跳过后续指引的问题。
- 已有用户不强制重走引导，设置中的独立白名单入口保留；不修改现有戒律和计时行为，不增加白名单状态检测或确认门禁。

## 验证范围

发布检查包含 `./scripts/check`（Debug/Release 各 41 项单元测试、Lint、Debug 与回归测试 APK 构建）、Release 构建、APK 元数据、原发布证书和 ZIP 对齐校验。

同功能 `c4bd8ce` 已在 Android 15/API 35 模拟器通过独立包五组回归，新增回归覆盖三步顺序、返回、仅同意说明后重开恢复、最后一步完成、断连时阻止完成及非首次独立入口。导航回归使用模拟连接状态，不代替真实系统授权验证。

同功能原签名 Release（0.3.11/code 14）已按用户要求卸载旧数据后全新安装 OPPO PLJ110（Android 16、ColorOS V16.1.0）。安装、签名/摘要、全新安装身份和欢迎页冷启动核对通过，旧应用数据及无障碍授权已清除，手机留在欢迎页；未替用户开始授权或走完整三步。本次 0.3.12/code 15 版本包未另装手机，不以功能构建代替版本包全量实测。

## 已知问题与边界

- OPPO 真实三步引导、无障碍授权/手机管家往返、实际进程被杀后的恢复、配置重建及短屏/大字号仍待专门复测。
- 「风险行为拦截」是部分厂商「手机管家」中的服务，入口因品牌和系统版本而异；白名单的实际防撤权效果尚未验证，服务被关闭或中断后仍需手动恢复。
- 真实顶部遮罩、物理旋转及系统入口、到期撤罩、锁屏/重连、完整自然周期和更多机型等未覆盖范围继续保留。真实来电挂断后的禁用恢复及大字号时长印章裁切仍有已知问题。
