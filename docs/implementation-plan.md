# Goule 实施计划

产品和技术决策以 [Android 首版设计](android-design.md) 为准。更新阶段状态时，附上检查结果或真机记录的位置。

## 当前任务：Android 能力原型

- [ ] 建立最小 Android 工程，提交 Gradle Wrapper，记录 JDK 和 Android SDK 版本，让 `./scripts/check` 执行本地构建检查。
- [ ] 实现单个调试目标的能力验证。用户同意并从系统设置启用服务后，观察进入目标 App、离开和锁屏，使用短额度触发遮罩。
- [ ] 按 [验证手册](verification.md) 在 Pixel 或接近原生的设备与至少一款国产 ROM 上验证前台事件、遮罩、桌面返回和系统入口。记录设备差异，明确原型能覆盖的场景。

通过能力验证后，再接入独立规则引擎与持久化，并完成规则配置、首次使用和服务异常恢复链路。各阶段的通过条件见 [设计稿的验证顺序](android-design.md#4-验证顺序)。

## 当前状态

仓库验证入口已就绪。Android 工程、能力原型与真机验证待开展。
