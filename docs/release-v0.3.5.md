# 斩心魔 v0.3.5

戒律列表和详情页现在都能查看每个 App 还可刷多长时间。继续作为预发布版本提供测试。

## 更新内容

- 列表在刷/禁配置下显示金色剩余时长，例如「还可刷 12 分 48 秒」。详情页的「当前戒律」卡片同步显示相同读数。
- 每个 App 按自己的已累计用量计算，返回页面时刷新；停留列表或详情不会扣减额度。
- 禁用中显示「还可刷 0 秒」，禁用到期或 24 小时使用窗口刷新后显示新一轮额度。禁用期间修改参数，仍保持本轮禁用为 0 秒。
- 整分钟显示分钟数，不足一分钟显示秒数，毫秒向上取整至秒。原有可刷、未生效、找不到 App 及禁用截止提示保留。

## 安装与验证

下载 `goule-v0.3.5.apk`，支持 Android 11 及以上，版本码 8。沿用原发布签名，可覆盖旧版并保留戒律和数据。安装后检查无障碍服务，部分系统需要重新开启。附 `goule-v0.3.5.apk.sha256` 校验文件。

本次发布包运行 `./scripts/check`（仓库检查、Debug/Release 各 12 项单元测试、Lint、Debug 构建）和 Release 构建，并校验 APK 版本、发布证书及 ZIP 对齐。证书与 v0.3.4 一致。

功能构建已在 Android 15 模拟器验证多 App 独立读数、实际使用后返回刷新、查看不扣时及预置禁用到期刷新；24 小时边界由纯 Kotlin 测试覆盖。OPPO PLJ110（Android 16、ColorOS 16.1.0）已核对原签名升级、列表和可刷详情显示、读数一致性及实际服务绑定。这些实机记录来自版本号仍为 0.3.4 的功能构建，本次 0.3.5 版本包未另装手机，不等同于全部真机回归通过。

## 已知问题与使用边界

- ColorOS 重启后可能撤销侧载应用的无障碍授权，需要手动重新开启；允许后台运行不能避免本机已观察到的撤权。
- 默认「智能优化后台运行」下划掉任务可能关闭服务。后台指引保持可选，具体设置由用户在系统中操作。
- 真实通话挂断后，仍在禁用中的目标 App 可能未自动恢复遮罩；返回桌面再进入可恢复，尚未修复。
- 同意权限说明但未开启服务时，重启 App 可能直接进入戒律首页；首页缺项提示及添加门禁仍有效，首次引导恢复问题尚未修复。
- 原有固定高度刷/禁印章在大字号下存在字形裁切。详情到期、短屏与大字号的完整实机显示，以及更多品牌设备仍待复测。
